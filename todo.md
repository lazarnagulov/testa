## DSL features

### Lexer
- [x] Arithmetic operators : +, -, *, /.
- [x] Bitwise operators : &, |, ^, <<, >>, ~.
- [x] Logical operators: &&, ||.
- [x] Comparison: ==, !=, <, >, <=, >=.
- [x] Integers
- [x] Strings
- [ ] Floats
- [ ] Range .., ..=
- [x] Directives
- [x] Built-ins
- [ ] Lookup

- [x] Fields : `string`: `expression` list

- [ ] Built-ins

- [ ] Resource statement
