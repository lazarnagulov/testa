    \section{Templates}
    \begin{listing}[h]

    \begin{minted}[escapeinside=||, xleftmargin=1em, breaklines]{cpp}
template <name> [: <parent_name>] {
    [override] <name1> = <expr>;
    [override] <name1> = <expr>;
    ...
}
    \end{minted}
    \centering
    \caption{Template declaration}
    \label{declaration:template}
    \end{listing}
    \par Templates are blueprints for creating reusable data structures or 
    types that are used in a "generate" expression. Each template has 
    a name and a set of fields, where each field is a pair consisting 
    of a string (the field name) and an expression (which defines the 
    field's value). By using data types and enumerations within these 
    expressions, you can add randomness to the values generated by the 
    template.
    \begin{listing}[h]
        \begin{minted}[escapeinside=||, xleftmargin=1em, breaklines]{cpp}
template User {
    id = int;
    name = |\textcolor{purple}{string}|;
    age = int;
}
        \end{minted}
        \caption{Example template in testA}
        \centering
        \label{listing:1}
    \end{listing}
    \subsection{Inheritence}
    \begin{listing}[h]
        \begin{minted}[escapeinside=||, xleftmargin=1em, breaklines]{cpp}
template User { age = int [range=0..=100]; }
template Student : User {
    year = int[range=1..=4];
    override age = int[range=19..=30];
}

        \end{minted}
        \caption{Inheritence example}
        \centering
        \label{listing:inheritance_example}
    \end{listing}

    \par Templates can be created from existing templates through a process 
    known as inheritance (Listing \ref{listing:inheritance_example}). A child template inherits all the fields from its 
    parent template and has the option to override any specific field by using 
    the "override" keyword and specifying the field name. 
    \par While using this keyword is not mandatory, incorrect usage may lead to a warning. 
    For example, Listing \ref{listing:override_example} will trigger a warning because the 
    field "age" is not overridden in the child template. It's important to note that all 
    repeated fields are overridden by default.
    \begin{listing}[h]
        \begin{minted}[escapeinside=||, xleftmargin=1em, breaklines]{cpp}
template User { 
    id = string;
    //age = int [range=0..=100]; 
}
template Student : User {
    year = int[range=1..=4];
    // User template does not have 'age' field!
    override age = int[range=19..=30];
}

        \end{minted}
        \caption{Override example}
        \centering
        \label{listing:override_example}
    \end{listing}

    \section{Enumerations}
    \begin{listing}[h]
        \begin{minted}[escapeinside=||, xleftmargin=1em, breaklines]{cpp}
enum <name> { 
     <variant1> [=> <expr:int>]; 
     <variant2> [=> <expr:int>]; 
     ...

        \end{minted}
        \caption{Enumeration declaration}
        \centering
        \label{declaration:enum}
    \end{listing}
    \par The "testA" enumerations include a list of names and their corresponding weights, which indicate the likelihood of randomly generating a variant. 
    Weights are always integers, with a default value of one if not specified.
    \begin{listing}[h]
        \begin{minted}[escapeinside=||, xleftmargin=1em, breaklines]{cpp}
enum Role {
    User => 8;
    Admin; // Default weight is 1
    Developer => 3;
}
        \end{minted}
        \caption{Enumerations in testA}
        \centering
        \label{listing:2}
    \end{listing}

    \section{Data types}
    \par Unlike other programming languages, such as C or Java, testA data types represent random values in expressions. 
    There are four fundamental data types available: integers (ints), floating-point numbers (floats), strings, and booleans.
    \begin{listing}[h]
        \begin{minted}[escapeinside=||, xleftmargin=1em, breaklines]{cpp}
template User {
    // Generates random string
    name = |\textcolor{purple}{string}|; 
    // Generates random integer
    age = int + 18; 
    // Generates random float
    salary = float + 300.0; 
    // Generates random boolean
    is_registered = !bool; 
}
        \end{minted}
        \caption{Template with data types}
        \label{listing:4}
    \end{listing}
    \par As demonstrated in Listing \ref{listing:4}, these types can interact with each other as well as with literals. 
    \subsection{Type constraints}
    \begin{listing}[h]
        \begin{minted}[escapeinside=||, xleftmargin=1em, breaklines]{cpp}
    
|\textcolor{keywordColor}{type}| <name> = <type> [<constraint1>, <constraint2>...];
|\textcolor{keywordColor}{type}| <name> = |\textcolor{keywordColor}{extend}| <type> |\textcolor{keywordColor}{with}| [<constraint1>, ...];
|\textcolor{keywordColor}{constraint}| <name> = <expr:bool>;

        \end{minted}
        \caption{Constrained type declaration}
        \label{declaration:type_constraint}
    \end{listing}

    \par The previous example (Listing \ref{listing:4}) does not depict a realistic individual, as the fields for age 
    and salary could potentially contain negative values. To address this issue, we can implement type constraints to prevent such errors. 
    These constraints can be easily added by enclosing them in brackets [ ] after the type name (Listing \ref{listing:5}), ensuring that the data 
    conforms to the expected parameters.
    \begin{listing}[h]
        \begin{minted}[escapeinside=||, xleftmargin=1em, breaklines]{cpp}
template User {
    name = |\textcolor{purple}{string}|[starts_with="A"];
    age = int[range=18..=100];
    salary = float[range=100..500] + 300.0;
    is_registered = bool[bias=75];
}
        \end{minted}
        \caption{Template with constrained data types}
        \centering
        \label{listing:5}
    \end{listing}
    \par To improve clarity and minimize redundancy, types may be effectively declared and reused (Listing \ref{listing:6}). 
    Furthermore, user-defined types can be expanded to offer greater versatility. 
    \par Check out Table 1 for an overview of the built-in constraints that apply to various types!
    \begin{listing}[h]
    \begin{minted}[escapeinside=||, xleftmargin=1em, breaklines]{cpp}
|\textcolor{keywordColor}{type}| Name = |\textcolor{purple}{string}| [starts_with="A"];
|\textcolor{keywordColor}{type}| Age = int [range=18..=100];
|\textcolor{keywordColor}{type}| MinimalSalary = float [range=100..500];
template User {
    name = |\textcolor{purple}{Name}|;
    age = |\textcolor{purple}{Age}|;
    salary = |\textcolor{purple}{MinimalSalary}|;
    is_registered = bool[bias=75];
}
        \end{minted}
        \caption{Template with user-defined data types}
        \centering
        \label{listing:6}
    \end{listing}
